## 1. 기획 배경

- 교육회사 CMS 저작툴(AI기능 탑재 교사향 외부 BM)을 기획 중이었으나, **매쓰캔버스 서비스에 저작툴 기능을 통합 출시**하는 방향으로 변경.
- 본 프로토타입은 **매쓰캔버스 인트로 페이지(목업)** 를 기반으로, 저작툴 진입·콘텐츠 선택 흐름을 새로 설계한 결과물.
- 서비스명은 **AI저작툴(가칭)**, 슬로건은 *Powered by 매쓰캔버스*.
- 디자인 톤앤매너는 매쓰캔버스 디자인 시스템(`reference/CLAUDE (1).md`)을 100% 준수.

## 2. 페이지·모달 구성도

```
[GNB · 학습설정+검색]
      │
      ├── 홈 (인트로 페이지) ────── 콘텐츠 row 5종 + "더보기 →"
      │                              └── 더보기 → 해당 카탈로그 탭으로 이동
      │
      ├── 조작형 콘텐츠 (카탈로그)
      ├── 차시 콘텐츠 (카탈로그)
      ├── 매쓰캔버스 (카탈로그)
      └── 문제은행 (카탈로그)
              + (좌측 사이드바 필터 영역 공유)

[+ 수업 만들기 CTA]
      └── 모달 1 [슬라이드 만들기 · 기본 정보]
             └── "슬라이드 만들기 →"
                    └── 모달 2 [콘텐츠 선택하기]
                           ├── 탭 A · 완성형 콘텐츠 불러오기 (4종 큰 버튼)
                           │      └── 모달 3 [{콘텐츠 종류} 불러오기]

```

## 7. 모달 3 — 콘텐츠 불러오기 (4종 통합 팝업)

### 7.1 공통 구조

- 타이틀: `{카테고리명} 불러오기`
- 서브탭: `나의 콘텐츠` / `공유 콘텐츠` (매쓰캔버스만 `나의 캔버스` / `공유 캔버스`)
- 필터 영역 → 카운트 + 뷰 토글 → 카드 그리드 → 페이지네이션 + 적용 버튼

### 7.2 매쓰캔버스 모드 (단일선택)

- 필터: 학교급 / 영역구분 / 검색 + **태그 칩 가로 스크롤** (좌우 화살표)
- 4-col 카드 (16:10 썸네일 + `✦ NEW` 뱃지 + 제목 + 날짜 + 미리보기)
- 단일 선택, `슬라이드에 적용하기`

### 7.3 문제은행 / 조작형 / 수업자료 모드 (복수선택, 동일 UI)

#### 필터 — 라벨 위에 표시, 6컬럼 grid

| 필드 | 컴포넌트 | 옵션 |
|------|----------|------|
| 학교급 | 셀렉트 | 초등학교 / 중학교 / 고등학교 |
| 학년 | 셀렉트 | 전체 + 1~6학년 |
| 교과목 | 셀렉트 | 수학 / 국어 / 영어 / 과학 / 사회 |
| 교과과정(단원명) | 셀렉트 | 전체 + 단원 목록 |
| 검색 | 셀렉트(`콘텐츠명` / `해시태그`) + 텍스트 인풋 | "검색어를 입력하세요" |
| - | `⟳ 초기화` 버튼 | 모든 필드 reset |

#### 카운트 메시지

| 모드 | 메시지 |
|------|--------|
| 문제은행 | 총 **35,448**개의 문항이 검색되었습니다. |
| 조작형 콘텐츠 | 총 **4,124**개의 콘텐츠가 검색되었습니다. |
| 수업자료 콘텐츠 | 총 **2,318**개의 콘텐츠가 검색되었습니다. |

#### 카드 (5-col 그리드)

- 좌상단: 체크박스 + 타입 배지
  - 객관식 = 회색 / 주관식 = 황색 / **조작형 = 민트** / **수업자료 = 그린**
- 썸네일: 16:10 영역에 미니 일러스트 SVG(텍스트 라인·표·도형·차트 등 8종 패턴) + 우하단 `문제/콘텐츠 미리보기` 흰색 오버레이 버튼
- 본문: `[타입] 제목` (1줄 truncate) + `◎ 출처` + `# 태그` (라운드 칩)

#### 복수선택

- 카드 클릭 시 선택 토글 (mint 보더 + 우상단 ✓ + 좌상단 체크박스 활성화)
- 우하단 `슬라이드에 적용하기` 버튼이 **선택 개수**까지 표시:
  - 0개 → 비활성
  - N개 → `슬라이드에 적용하기 (N)`

## 8. 모달 4 — 콘텐츠 미리보기

`문제 미리보기 / 콘텐츠 미리보기` 버튼 클릭 시 진입.

- 헤더: 타입 배지 + `[타입] 제목`
- 본문: 16:9 슬라이드 스테이지에 안내 문구 + 큰 일러스트 (썸네일 SVG 재활용)
- 메타: **출처** + **태그**
- 푸터: `닫기` / `이 콘텐츠 선택` → 닫으면서 해당 카드를 선택 상태로 추가

## 9. 디자인 시스템 (요약)

> 전체 가이드는 `reference/CLAUDE (1).md` 참고. CSS 변수만 사용하며 임의 HEX 금지.

### 핵심 토큰

| 카테고리 | 변수 | 값 | 용도 |
|---------|------|-----|------|
| 배경 | `--bg` | `#F4F5F7` | 페이지 |
| | `--paper` | `#FFFFFF` | 카드/패널/모달 |
| 브랜드 | `--mint` | `#00B8B6` | Primary, 활성 상태 |
| | `--mint-soft` | `#CCEFEF` | 선택 배경 |
| 구분선 | `--line` | `#E5E7EB` | 모든 border 기본값 |
| 텍스트 | `--ink` ~ `--ink-4` | 4단계 | 위계 |
| 섹션 | `--creative/curriculum/tool/theme` | + `-soft` | 카테고리 구분 |

### 컴포넌트

- **카드**: `border-radius: 10–12px`, ring shadow `0 1px 3px rgba(0,0,0,0.06), 0 0 0 1px rgba(0,0,0,0.07)`
- **Primary 버튼**: `--mint` 배경 + 흰 텍스트, `8px` radius
- **입력 필드**: `--bg-2` 배경 + `7px` radius
- **자간**: 한국어 UI는 항상 **음수** (`-0.005em` ~ `-0.03em`)
- **폰트**: Pretendard, Noto Sans KR fallback

### 안티 패턴 (절대 사용 금지)

- 베이지/크림 배경, 검정 Primary, 파란색 UI, Pill 버튼(18px+), 회색 아이콘, 양수 자간

## 10. 인터랙션 흐름

### 10.1 새 슬라이드 시작 (Golden path)

```
[+ 수업 만들기]
   ↓
[슬라이드 만들기] 기본 정보 입력 (교과목 영어 시 단원 → Lesson 자동 갱신)
   ↓ "슬라이드 만들기 →"
[콘텐츠 선택하기]
   ├─ [완성형 콘텐츠] → [{종류} 불러오기] → 카드 복수선택 → "슬라이드에 적용하기 (N)"
   │       └─ 카드 미리보기 → [콘텐츠 미리보기 모달] → "이 콘텐츠 선택"
   └─ [템플릿] → 카테고리 선택 → 썸네일 선택 → "선택 완료"
        ↓
   편집 화면으로 이동 (현재 프로토타입은 toast 메시지로 시뮬레이션)
```

### 10.2 카탈로그 탐색

```
GNB 탭 클릭 OR 인트로 row의 "더보기 →"
   ↓
[카탈로그 페이지] (사이드바 필터 + 카드 그리드)
   ↓ 카드 클릭
편집 화면으로 이동 (toast)
```

## 11. 결정 사항 vs 미정 사항

### ✅ 결정 사항

- 서비스명: **AI저작툴(가칭)**, 매쓰캔버스 브랜드 하위
- 디자인 시스템 100% 매쓰캔버스 가이드 준수
- 인트로 페이지의 검색 영역은 **학습 설정 셀렉트와 한 줄로 통합**
- 다크 공지 패널의 메타 수치(차시 콘텐츠/디지털 교구/핵심 개념) **삭제**
- "더보기 →" 클릭은 **GNB 탭 진입과 동일한 화면**으로 이동
- 모달 2 명칭: **콘텐츠 선택하기**, 부 카피 통일
- 완성형 콘텐츠 4종 (조작형 / 수업자료 / 매쓰캔버스 / 문제은행)
- 템플릿 카테고리 4종 (일반 페이지 / 1분 퀴즈 / 조작형 / 문항)
- 문제은행·조작형·수업자료 불러오기 팝업 **UI 동일 (5-col + 복수선택 + 미리보기)**
- 매쓰캔버스 불러오기는 단일선택 + 태그 칩 (별도 UI)

### 🟡 미정 / 추가 검토 필요

1. **명칭 통일**
   - 인트로 GNB 탭은 `차시 콘텐츠`, 완성형 카드는 `수업자료 콘텐츠` → 통일 여부 결정 필요
2. **콘텐츠 분류 중복**
   - `조작형 콘텐츠` (4,000여 종) vs `매쓰캔버스` (47종 디지털 교구) → 분류 기준 정의 필요
3. **인트로 row 큐레이션**
   - `오늘 수업 바로 쓰기`의 추천 로직(개인화/시간/단원)
   - `오늘 수업 바로 쓰기` 더보기는 현재 `차시 콘텐츠` 탭으로 매핑 — 별도 큐레이션 페이지 필요 여부
4. **차시(단원) 데이터**
   - 영어 외 교과의 단원 옵션 — 교과서 출판사·학년별 실제 데이터 연동 방안
5. **불러오기 팝업 동작**
   - 필터·정렬·페이지네이션의 실제 API 연동 / 무한스크롤 vs 페이지네이션
   - 검색 셀렉트 옵션 추가 여부 (현재 `콘텐츠명` / `해시태그` 2종)
6. **미리보기 모달**
   - 실제 콘텐츠 렌더링 방식 (iframe? 별도 viewer 컴포넌트?)
   - 미리보기에서 다음/이전 콘텐츠로 이동하는 캐러셀 기능 필요 여부
7. **편집 화면 연결**
   - "슬라이드에 적용하기" 후 어떤 식으로 편집 화면(매쓰캔버스 슬라이드 에디터)으로 진입할지
   - 다중 콘텐츠를 동시에 적용했을 때 슬라이드 구성 방식 (각 콘텐츠 = 1 슬라이드?)
8. **권한·공유**
   - "나의 캔버스/콘텐츠" vs "공유 캔버스/콘텐츠" 권한 모델
   - 비상교육 스마트 문제은행 연동 인증 방식
9. **접근성**
   - 키보드 네비게이션, 스크린 리더, 포커스 트랩(모달)
   - 모달 ESC 닫기는 구현됨, 그 외 a11y 점검 필요

## 14. 후속 작업 가이드

이 문서를 기반으로 다음 페이지/플로우 기획을 이어가실 때 권장 순서:

1. **편집 화면 (슬라이드 에디터)** — 적용 후 진입할 메인 워크스페이스
2. **나의 프로젝트 / 공유 프로젝트** — 좌측 사이드 메뉴에서 진입하는 리스트 페이지
3. **활동 만들기** — 우상단 CTA (새로만들기2.png에 일부 노출)
4. **수업하기** — 슬라이드 실행 모드 (학생 화면 + 교사 컨트롤)
5. **활동 리포트** — 실행 후 데이터 분석 페이지

각 페이지 기획 시 본 프로토타입의 디자인 토큰·컴포넌트(.card / .modal / .picker-* / .qb-* / .gallery 등)를 재사용하면 톤앤매너가 유지됩니다.
