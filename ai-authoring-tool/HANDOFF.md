## 1. 기획 배경

- 교사·출판사·학원 대상의 **외부 BM** 으로 활용 가능한 콘텐츠 플랫폼.
- 흩어진 수업 콘텐츠(활동형/수업자료/매쓰캔버스/스마트 문제은행/스마트 교과서)를 한 곳에 모아 클릭 한 번으로 슬라이드 수업을 완성.
- 게이트 페이지는 어드민형 카탈로그가 아닌 **프리미엄 마케팅 그레이드 다크 랜딩**으로 설계.
- 모든 콘텐츠 선택 흐름은 **게이트 위에서 완결**되고, 최종 적용 시에만 슬라이드 편집 화면으로 진입.

## 2. 화면 구조 / 진입 흐름

```
[ gate.html ] (메인 게이트 · 다크 프리미엄)
│
├── 학습 설정 (톱니) ──── 학교급/학년/교과목/차시 → DECK 저장 → 메인/팝업/필터 기본값에 자동 적용
│
├── 수업 만들기 ─── [슬라이드 만들기 팝업]
│                       │
│                       └── [콘텐츠 선택하기 팝업]  (게이트 위에서 노출)
│                                ├── 완성형 콘텐츠 5종 카드 → [불러오기 로더] (복수선택 + 미리보기) ─┐
│                                └── 템플릿 갤러리(카테고리 사이드바 + 썸네일)                    ├─→ 선택 완료/적용
│                                                                                                ↓
│                                                                                  [에디터 화면(index.html)으로 핸드오프]
│
└── 콘텐츠 담기 (스테이지 CTA) ── [카테고리 상세(다크)]
                                     ├── 상단 카테고리 스위처 (페이지 이동 없이 5종 전환)
                                     ├── 좌측: 카테고리별 차등 필터
                                     └── 카드 그리드 (복수선택 + 미리보기 + 슬라이드 적용바)
                                                ↓
                                  [에디터 화면(index.html)으로 핸드오프]

[ index.html ] (저작툴 / 에디터)
- 게이트에서 ?step=editor&slides=...&name=... 으로 진입 시 곧바로 편집 화면
- 좌측 슬라이드 사이드바 / 중앙 캔버스 / 우측 컨텍스트 패널 / 하단 줌·노트
- 좌상단 ← 뒤로 → gate.html로 복귀
```

## 4. 게이트 페이지 (gate.html)

### 4.1 다크 프리미엄 랜딩 — 섹션 구성

| 섹션 | 내용 |
|------|------|
| 글래스 네비 (스크롤 시 활성) | 브랜드 · 콘텐츠 · 왜 AI저작툴 · 수업 사례 · 시작하기 · **학습 설정(톱니)** · **수업 만들기(CTA)** |
| 히어로 | 오로라 그라데이션 + 떠다니는 슬라이드 목업 3종 + 플로팅 배지(자동 채점/실시간 협업) |
| 통계 밴드 | 96,589 / 9,672 / 171,668 / 428 + "매주 업데이트" 안내 |
| **콘텐츠 라이브러리** | 5개 카테고리 탭 + 인터랙티브 스테이지(타이틀/설명/기능/해시태그/디바이스 목업/`OOO 담기` CTA) |
| 왜 AI저작툴 | 5분 완성 · 교육과정 정렬 · 참여 인터랙션 |
| 수업 사례 캐러셀 | 호버 시 재생 오버레이, 카드 클릭 → 카탈로그 |
| 3단계 플로우 | 학습 설정 → 콘텐츠 담기 → 수업 실행 |
| 마지막 CTA / 푸터 | `수업 만들기 시작` 등 |

> GNB 앵커 클릭 시 섹션이 고정 네비 아래로 잘리지 않도록 `html { scroll-padding-top: 88px }` 적용.

### 4.2 학습 설정(톱니) 모달

- 필드: **학교급 / 학년 / 교과목 / 차시(단원)** — 교과목 변경 시 단원 옵션 동적 갱신.
- 저장 시 `DECK` 상태 갱신, `gateSubject` 변경 → 메인 스테이지/사례/카탈로그/필터 즉시 재렌더, `슬라이드 만들기 팝업`과 `불러오기 필터`의 기본값으로 자동 반영.
- 게이트 상단 네비 + 카테고리 상세 상단 모두에서 진입 가능.

### 4.3 교과목별 콘텐츠 팩

`PACKS` 객체에 정의된 교과목별 오버라이드. 현재 **수학(기본) + 영어 예시** 제공.

| 영역 | 수학 | 영어 |
|------|------|------|
| 스테이지 타이틀/설명/기능 | 분수·도형 중심 | 영단어·문장·표현 중심 |
| 해시태그 | 분수 모형 · 수직선 · 확률 돌림판 … | 영단어 퀴즈 · 발음 연습 · 빈칸 채우기 · 플래시카드 … |
| 디바이스 목업 | 분수 모형 / 좌표 / 문항 / 교과서 양면 | 플래시카드 / Lesson 대화 / 문장 배열 / be동사 문법 / 교과서 양면 |
| 사례 카드 | 분수·다각형·좌표 … | 플래시카드 · Lesson 1 · 문장 카드 · 어휘 평가 … |
| 카테고리 상세/로더 콘텐츠 | 수학 콘텐츠 | 영어 콘텐츠 |
| 영역 필터 | 수와 연산 · 도형과 측정 · 변화와 관계 · 자료와 가능성 | 어휘 · 문법 · 듣기 · 말하기 · 읽기·쓰기 |

그 외 교과목은 수학 콘텐츠로 폴백 + "순차 오픈 예정" 안내.

## 5. 슬라이드 만들기 / 콘텐츠 선택 흐름 (게이트 위에서 완결)

### 5.1 슬라이드 만들기 팝업 (`gm-create`)

- 필드: 슬라이드 이름(오늘 날짜 자동) · 학교급 · 학년 · 교과목 · 차시(단원)
- 학습 설정값 기본 반영, 교과목 변경 시 단원 옵션 동적 변경
- `슬라이드 만들기 →` → **콘텐츠 선택하기 팝업** 진입 (게이트 위에서 노출, 툴 페이지 노출 없음)

### 5.2 콘텐츠 선택하기 (`gm-select`)

상단 2개 탭:

**A) 완성형 콘텐츠 불러오기** — 5종 카드
- 활동형 · 수업자료 · 매쓰캔버스(수학 전용) · 스마트 문제은행 · 스마트 교과서
- 카드 클릭 시 **로더 모달(`gm-loader`)** 진입

**B) 템플릿 불러오기** — 카테고리 사이드바 + 썸네일 갤러리
- 카테고리: 일반 페이지 / 1분 퀴즈 / 활동형 / 문항 / 활동 (활동 템플릿은 채점 안내 툴팁)
- 단일 선택 → `선택 완료` → 에디터로 핸드오프

### 5.3 콘텐츠 불러오기 로더 (`gm-loader`)

- 필터: 학교급 · 영역 · 검색
- 카드: **복수 선택** + **`미리보기` 버튼**
- 카운트 표시 + 선택 개수 동기화
- `슬라이드에 적용하기 (N)` → 선택한 콘텐츠를 각각 슬라이드로 → 에디터 핸드오프

### 5.4 콘텐츠 미리보기 (`gm-preview`)

- 카테고리 상세/로더 공용 모달
- 표시: 타입 배지 · 제목 · 출처 · 태그 · 스니펫 시각
- `선택에 추가` → 현재 컨텍스트(cat-view/로더)의 선택에 즉시 반영

## 6. 카테고리 상세 페이지 (게이트 내 다크 풀스크린)

스테이지의 `OOO 담기` CTA로 진입. 페이지 이동 없이 카테고리 전환.

### 6.1 레이아웃

- 상단 sticky: 뒤로 · 카테고리명 + 개수 · 톱니 · 수업 만들기
- 그 아래: **카테고리 스위처 칩** (활동형·수업자료·매쓰캔버스·스마트문제은행·스마트교과서) — 활성 카테고리 컬러로 강조
- 좌측: 카테고리별 차등 필터 (학년/영역/...)
- 우측: 카드 그리드 — **카드별 체크박스(복수선택) + 미리보기 버튼**
- 하단: `N개 선택됨 / 선택 해제 / 슬라이드에 적용하기` 플로팅 바

### 6.2 카테고리별 좌측 필터

| 카테고리 | 필터 옵션 |
|---------|----------|
| 활동형 콘텐츠 | 학년 / 영역 / **활동 유형**(드래그·퀴즈·게임·그리기) / **난이도**(기초·보통·심화) |
| 수업자료 콘텐츠 | 학년 / 영역 / **수업 단계**(도입·전개·정리·형성평가) / **차시**(1·2·3차시 이상) |
| 매쓰캔버스 | 학년 / 영역 / **교구 유형**(2D·3D·그래프·도형) / **학습 형태**(개인·모둠) |
| 스마트 문제은행 | 학년 / 영역 / **문항 유형**(객관식·주관식 / 영어: + 듣기형) / **난이도**(하·중·상) |
| 스마트 교과서 | 학년 / 영역 / **학기**(1·2학기) / **보기 형태**(양면·한쪽) |

영역 칩은 교과목에 따라 동적(수학=수와 연산… / 영어=어휘·문법·듣기…). 영어 카테고리 상세에서 일부 필터(활동 유형/수업 단계·언어 기능/문항 유형)는 영어 전용 옵션으로 자동 전환.

영역 칩 선택 시 카드 그리드가 실제로 필터링됩니다.

## 7. 에디터 (index.html)

게이트에서 `?step=editor&slides=<json>&name=<deck명>` 으로 진입 시 곧바로 편집 화면 노출.

### 7.1 레이아웃 (참고 이미지 기준)

- 상단: ← 뒤로(게이트로 복귀) · 슬라이드명 · 실행취소/다시실행 · 저장 · ⚙(학습 설정) · 활동 만들기 · ▶ 수업하기
- 좌측: 슬라이드 사이드바(번호 + 썸네일 + 핸들 + `+` 추가)
- 중앙: 16:9 캔버스 (선택 콘텐츠 시각 렌더)
- 우측: 컨텍스트 패널(타입 헤더 + 불러오기 버튼 + 콘텐츠 정보)
- 하단: 발표자 노트 · 줌 슬라이더

### 7.2 슬라이드 타입 5종 + 템플릿

| 타입 | 썸네일 우상단 아이콘 | 색 |
|------|---------------------|-----|
| 매쓰캔버스 | 파란 `M` | DBEAFE |
| 문제은행 | 주황 돼지저금통 | FEF3C7 |
| 수업자료 | 초록 책 | D4EDE5 |
| 활동형 | 민트 블록 | CCEFEF |
| 스마트 교과서 | 블루 펼친 책 | DCE7FB |
| 템플릿 | 보라 레이아웃 | E4E1F8 |

### 7.3 핵심 동작

- **1 슬라이드 = 1 아티클** — 복수 선택 시 각 아티클이 개별 슬라이드로 분할 생성
- 우측 패널 `OOO 불러오기` 버튼 → 해당 타입 로더 → 슬라이드 교체/추가
- `+` 버튼 → 슬라이드 추가 사이드바(페이지/퀴즈 만들기 분리)
- 줌·뒤로가기·학습설정 모달 모두 동작

## 11. 주요 데이터 구조 메모

### gate.html

| 변수 | 설명 |
|------|------|
| `CATS` | 5개 카테고리 (id/name/count/color/icon/eyebrow/screenTag/title/desc/feats/tags) |
| `SECTION_FOR` | gate cat id → picker kind 매핑 |
| `IMPORT_META` | picker kind → 라벨/색/단위 |
| `TOTALS` | 카운트 |
| `PICKER_DATA` | 수학 기본 콘텐츠 (manipulative/lesson/canvas/qbank/textbook) |
| `PACKS['영어']` | 영어 교과 콘텐츠 팩 (cats override + showcase + picker + areas) |
| `gateSubject` | 현재 교과목 (학습 설정에서 갱신) |
| `TPL_CATS` | 템플릿 카테고리/리프 |
| `DECK` | 학습 설정 상태(name/school/grade/subject/unit) |
| `catKinds()` | 매쓰캔버스 비수학 시 제외하여 반환 |
| `catFilters(kind)` | 카테고리별 차등 필터 (영어 인지) |

### index.html (저작툴)

| 변수 | 설명 |
|------|------|
| `SLIDE_TYPE_META` | 슬라이드 타입 → 라벨/로더 라벨/빈 메시지/pickerKind |
| `slideTypeIcon(kind)` | 5종 + 템플릿 아이콘 |
| `QBANK_MODES` | qbank 스타일 모달 모드 (qbank/manipulative/lesson/textbook) |
| `QBANK_LABELS/UNITS/TOTALS` | 모드별 라벨·단위·합계 |
| `PICKER_DATA` | 콘텐츠 데이터 |
| `LEARN` | 학습 설정 상태 |
| `applyLearnTo*` | LEARN을 모달/필터 기본값에 적용 |
| `editorSlides / activeSlideIdx` | 에디터 상태 |

### 게이트 → 에디터 핸드오프

```
index.html?step=editor
  &name=<deck명>
  &slides=<JSON encodeURIComponent>
```

`slides`는 `slideFromContent / slideFromTemplate`로 만든 객체 배열(JSON).
index.html은 이를 받아 `editorSlides`로 설정하고 `openEditor()`를 호출, 곧장 편집 화면을 띄움.

## 13. 후속 작업 가이드

본 프로토타입을 기반으로 이어갈 권장 순서:

1. **에디터 워크스페이스 고도화** — 슬라이드 실제 렌더, 정렬/삭제/복제, 발표자 노트, 학생 응답 화면
2. **수업하기(실행 모드)** — 학생 화면 + 교사 컨트롤(다음 슬라이드/응답 집계/타이머)
3. **활동 만들기** — 빠른 활동 생성(투표/퀴즈/협업) 별도 플로우
4. **활동 리포트** — 실행 후 응답 데이터 분석/내보내기
5. **나의 프로젝트 / 공유 프로젝트** — 저장된 덱 관리, 공유 권한
6. **AI 기능 정의** — 자동 슬라이드 생성, 콘텐츠 추천, 자동 채점·피드백
7. **교과목 팩 확장** — 국어/과학/사회 데이터·디바이스 목업

각 화면 기획 시 본 프로토타입의 디자인 토큰(게이트 다크 + 매쓰캔버스 라이트), 컴포넌트(.cv-*, .gm-*, .gsel-*, .gload-*, .ed-* 등)를 재사용하면 톤앤매너가 유지됩니다.
